## Featured project

### Data Quality & Annotation Review
A beginner-friendly, no-code quality assurance project using fictional e-commerce customer-support messages.

**What it demonstrates**
- Reviewing pre-labelled text data
- Identifying incorrect and missing annotations
- Detecting duplicate record IDs
- Applying consistent annotation guidelines
- Documenting quality findings and reviewer decisions
